Rumus & Cara Menghitung Sesuai Modul 7

Penjelasan matematis detail cara kerja peminjaman bit dan pembentukan subnet

1 Menghitung Kebutuhan Bit Host (x) dan Netmask

Jumlah IP dalam satu subnet dihitung dengan rumus 2x. Karena 2 alamat wajib direservasi untuk Network ID dan Broadcast ID, maka jumlah user maksimal yang dapat ditampung adalah:

Jumlah User Maksimal = (2x - 2) ≥ Kebutuhan User

• Jika kebutuhan = 26 user → 25 - 2 = 30 ≥ 26 → x = 5 bit host.

• Netmask dihitung dari 32 bit total: Netmask = 32 - x = 32 - 5 = 27 (/27).

• Subnet mask desimal: 256 - 32 = 255.255.255.224.

2 Nilai Pangkat Bit pada Oktet ke-4 (8 Bit)

Bit yang dipinjam selalu dimulai dari kiri (MSB / bit bernilai tertinggi):

Bit 1 27 128
Bit 2 26 64
Bit 3 25 32
Bit 4 24 16
Bit 5 23 8
Bit 6 22 4
Bit 7 21 2
Bit 8 20 1

Contoh Modul: Jar 4 (Path 010) → [0 1 0] 0 0 0 0 0 = 0×27 + 1×26 + 0×25 = 64 → IP: 192.168.15.64/27

Contoh Modul: Jar 5 (Path 100000) → [1 0 0 0 0 0] 0 0 = 1×27 = 128 → IP: 192.168.15.128/30

Contoh Modul: Jar 6 (Path 100001) → [1 0 0 0 0 1] 0 0 = 1×27 + 1×22 = 128 + 4 = 132 → IP: 192.168.15.132/30
